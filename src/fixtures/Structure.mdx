# Structure

Grouping, revealing and measuring content with MUI components from `@mui/material`, used as MUI documents them and themed as stock MUI. There are no wrapper components. Icons come from `src/icons`.

## Accordion

A stack of titled sections the user expands. Use `Accordion` with `AccordionSummary` (give it an `id`, `aria-controls` and `expandIcon={<ChevronDownIcon />}`) and `AccordionDetails`. For one open at a time, control `expanded` and close the others in `onChange`; for several, let each item keep its own state. `disableGutters` stops the open item from adding margin around itself in a dense list.

<Canvas of={StructureStories.AccordionRecipe} />

## Collapse

One section of secondary detail that can be shown or hidden. A text `Button` with `aria-expanded`, `aria-controls` and a `ChevronDownIcon` end icon toggles a `Collapse` with the matching `id`. Use an accordion instead when there are several such sections.

<Canvas of={StructureStories.CollapseRecipe} />

## Progress

How far a running task has got: `LinearProgress` with `variant="determinate"` and a `value` from 0 to 100, under a visible label it points at with `aria-labelledby`, with the percentage beside the label. Leave out `variant` when the end is unknown, and drop the percentage. Use `CircularProgress` only inside a control too small for a bar.

## Meter

A static level within a known range, such as occupancy, not a task's progress. MUI has no meter: use a determinate `LinearProgress` with the same label, and set `role="meter"` with `aria-valuemin`, `aria-valuemax` and `aria-valuetext` so assistive technology does not announce it as a task in progress.

<Canvas of={StructureStories.MeterRecipe} />

## Avatar

A person: `Avatar` with `src` and `alt`, with the person's initials as children so they show if the image fails. With no photo, pass only the initials and mark the avatar `aria-hidden`, since the name beside it is the readable text. Set the name (`subtitle2`) and role (`body2`, `color="text.secondary"`) beside it in a `Stack`. The story's photo is a local asset, `src/assets/avatar-photo.svg`; in the app, pass the person's image URL from the API.

## Scrolling region

A fixed-height region that scrolls inside the page, in place of a custom scroll area. Use an outlined `Paper` (flat, with a divider border, like Kilowatt's cards) with a `height` and `overflow: 'auto'` in `sx`. Because it scrolls, give it `tabIndex={0}`, `role="region"` and an `aria-label`, so keyboard users can reach and scroll it. The browser draws the scrollbar.

## Divider

A 1px divider-colored rule between two groups of content: `Divider`. Menus use it between groups of items. Use `orientation="vertical"` with `flexItem` inside a row.

## Kilowatt rules

- Surfaces are flat and outlined: `Paper variant="outlined"` (and `Card`, which is outlined by default), not elevation.
- Don't pass colors; text uses Typography's palette roles such as `color="text.secondary"`. Use `sx` only for layout.

## Do and don't

- Do use progress for a task moving toward done and a meter for a level that is simply measured.
- Do give every progress bar and meter a visible label.
- Don't hide information the user needs to act on inside a collapsed panel.
- Don't use a divider where spacing alone separates the groups.

## Accessibility

- `AccordionSummary` is a button with `aria-expanded`, linked to its panel by the `id` and `aria-controls` you pass.
- `LinearProgress` sets `role="progressbar"` and `aria-valuenow` when determinate; the caller names it with `aria-labelledby`.
- A scrolling region must be focusable and named, or keyboard users cannot scroll it.
