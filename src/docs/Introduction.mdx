# Kilowatt

Kilowatt is Enertiv's design system. It is Material UI with light and dark color schemes, changed only where a departure says so: the palette (surfaces, borders, a navy primary (light neutral in dark), a brand-blue secondary, a purple info, intent colors), the corner radius, the button style, the icon set, type rendering (tabular numerals, text wrapping, no synthesized styles) and reduced motion. Foundations → MUI departures lists every one; anything not listed there is MUI's default, on purpose.

This site is public at `https://kilowatt-ui.vercel.app`, with no login. Your coding agent can read it too, through the MCP server at `/mcp`.

## Connect your agent

Point your agent at this URL:

```text
https://kilowatt-ui.vercel.app/mcp
```

It's a remote MCP server over HTTP, with no key or token. Set it up once per project:

- **Claude Code.** Run this in your project:

  ```bash
  claude mcp add --transport http --scope project kilowatt https://kilowatt-ui.vercel.app/mcp
  ```

  Or add it to the project's `.mcp.json` by hand:

  ```json
  {
    "mcpServers": {
      "kilowatt": { "type": "http", "url": "https://kilowatt-ui.vercel.app/mcp" }
    }
  }
  ```

- **Cursor.** Add the same `kilowatt` entry, with only `url`, under `mcpServers` in `.cursor/mcp.json`.
- **VS Code.** Add it under `servers` in `.vscode/mcp.json`, as `{ "type": "http", "url": "https://kilowatt-ui.vercel.app/mcp" }`.
- **Claude (web and desktop).** Under **Settings → Connectors**, add a custom connector with the URL.
- **Agents that only fetch URLs.** Start them at [`https://kilowatt-ui.vercel.app/llms.txt`](./llms.txt).

Then tell the agent to use it. A line like this in your project's `AGENTS.md` or `CLAUDE.md` does it:

```md
Before writing UI, read Kilowatt's rules and MUI departures with the `kilowatt` MCP server (`docs-list`, then `docs-show`). Build with Material UI as MUI documents it.
```

### What the server gives an agent

| Tool | What it returns |
| --- | --- |
| `docs-list` | Every component and guide, with its id. |
| `docs-show` | One component's description, import line, props, guidance and story snippets, or one guide. |
| `docs-show-story` | One story's snippet. |

Each deployment serves an MCP server built from the same commit as its Storybook, so the docs an agent reads always match the site.

## Set up MUI in an app

Kilowatt has no package. An app gets it by installing MUI and copying the theme from this repository, then builds with MUI components. Don't recreate the theme with your own CSS, and don't build Kilowatt UI in static HTML.

1. **Install MUI and its peers** (React 19):

   ```bash
   npm install @mui/material @emotion/react @emotion/styled
   ```

2. **Load the fonts.** Roboto at MUI's four weights, and the Material Symbols variable icon font, in the page's `<head>`:

   ```html
   <link rel="preconnect" href="https://fonts.googleapis.com" />
   <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
   <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@300;400;500;700&display=swap" rel="stylesheet" />
   <link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200&display=block" rel="stylesheet" />
   ```

3. **Copy the theme.** These files, unchanged and in the same folders: `src/mui/theme.ts`, `src/mui/departures.ts`, `src/mui/colors.ts`, `src/mui/augmentation.ts`, `src/mui/MuiProvider.tsx` and `src/icons.tsx`. They import only each other and MUI.
4. **Wrap the app in `MuiProvider`.** It applies the theme and MUI's `CssBaseline`. Switch light and dark with MUI's `useColorScheme().setMode`. Guides → Host setup lists what else an app provides for charts, maps and server rendering.

   ```tsx
   import { MuiProvider } from './mui/MuiProvider';

   createRoot(document.getElementById('root')!).render(
     <MuiProvider>
       <App />
     </MuiProvider>,
   );
   ```

5. **Check it's running.** Render a `<Button variant="contained">` and an `<Icon name="search" />` and confirm in the browser:
   - The button is the navy primary, flat, with 8px corners and its label as written, not MUI's default blue, shadowed, uppercase button.
   - The icon draws a magnifying glass, not the word “search”: the icon font loaded.
   - `document.fonts.check('16px Roboto')` returns `true`.
   - The page background follows the color scheme when you call `setMode('dark')`.

   If any check fails, fix the setup before building screens.

When the theme changes here, copy the files again. Never edit the copies: a change to the theme is a departure, made in this repository.

## Where things are

| Section | What it holds |
| --- | --- |
| **Guides** | The rules for using the system, how to write stories, the data layer and the stack. Start with **Rules**. |
| **Foundations** | **MUI departures**, every way Kilowatt differs from stock MUI. Then the theme's values, each marked as MUI's default or a departure: color, typography, spacing, shape, elevation, layout, z-index, motion and icons. |
| **Components** | MUI components as Kilowatt uses them, each with one story per variant and state and guidance on when to use it. Starts with **Button**. |

## Building with Kilowatt

1. **Use MUI as MUI documents it.** Components, props, variants and palette roles come from MUI's documentation.
2. **Take values from the theme.** Color, type, spacing, radius, elevation and motion come from the MUI theme, through component props or `sx` theme keys. Never a hex value, a pixel radius or a font family of your own.
3. **Add conventions as departures.** Anything that differs from MUI's default is an entry in `src/mui/departures.ts`, with its reason, so it shows on Foundations → MUI departures.

## Without MCP

MCP isn't available everywhere: a browser or an agent that only fetches URLs can't call `/mcp`. Read the same content as Markdown instead, in this order:

1. [`llms.txt`](./llms.txt), the index of every page.
2. `guides/rules.md`, the rules.
3. `foundations/mui-departures.md`, every way Kilowatt differs from stock MUI.
4. `foundations/typography.md` and `foundations/color.md`, the type styles and palette roles with their values.
5. `components/<id>.md` for each component the screen uses, linked from `llms.txt`.

Each deployment builds these files and its MCP server from the same commit, so they never disagree.

## Other ways agents read Kilowatt

- **Local MCP, for work on Kilowatt itself.** In this repository, `npm run storybook` serves an MCP server at `http://localhost:6006/mcp`, which `.mcp.json` already registers as `kilowatt-storybook`.
- **llms.txt.** [`llms.txt`](./llms.txt) indexes every page as Markdown: `guides/<slug>.md` and `foundations/<slug>.md`.
- **Manifests.** Every build serves `/manifests/components.json` and `/manifests/docs.json`.
