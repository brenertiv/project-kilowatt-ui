# PageHeader

<Canvas of={PageHeaderStories.Default} />

## When to use

- At the top of every page view in `src/pages`, exactly once.
- A detail page: breadcrumbs to the record, the record type as `eyebrow`, its name as `title`, status chips in `meta`, actions on the right.
- A list page: the collection's name and a primary action such as "New work order".

## When not to use

- Inside a card or section: use a section heading. A page has one `PageHeader` and one `h1`.
- For a record's details: put them in an [EntityCard](?path=/docs/data-entitycard--docs) below the header, not in `meta`.
- For headline numbers: use a row of [StatCard](?path=/docs/data-statcard--docs)s below the header.

## Do and don't

Do:

- Give breadcrumbs from the top of the app to this page, current page last and without `to`.
- Use `eyebrow` for the entity type ("Building", "Work order") and `title` for its name.
- Put the page's primary action last in `actions`, after any secondary ones.
- Pass `state` while the record loads, so the title and description show skeletons instead of an empty heading.
- Keep `description` to one or two sentences on what the page is for.

Don't:

- Don't put more than a few chips or facts in `meta`; detail belongs in the page body.
- Don't print a placeholder record name as the title. Resolve it the way `EntityName` does, or pass the `EntityName` component as `title`.
- Don't add a second `PageHeader` for a tab or section.

## Accessibility

- Renders a `header` landmark with the page's only `h1`.
- Breadcrumbs are a navigation landmark labelled "Breadcrumb"; linked crumbs are links, the current page is plain text.
- While loading, the title and description are skeletons and `meta` is hidden.
- The caller provides visible labels or `aria-label`s for the buttons in `actions`.

## Composition

- The first thing on a page, followed by [StatCard](?path=/docs/data-statcard--docs)s, an [EntityCard](?path=/docs/data-entitycard--docs), or a [FilterBar](?path=/docs/data-filterbar--docs) and [EntityList](?path=/docs/data-entitylist--docs).
- `meta` usually holds [StatusChip](?path=/docs/data-statuschip--docs)s or `DateText`.
- Uses the record's `AsyncState`, the same one passed to [DataState](?path=/docs/data-datastate--docs) and the components below it.
