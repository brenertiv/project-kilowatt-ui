# StatCard

## When to use

- The few numbers a page leads with: consumption, spend, peak demand, open work orders.
- In a grid of three to six cards at the top of a page or dashboard, under the `PageHeader`.
- When the number has a comparison period and a direction that is good or bad.

## When not to use

- A number inside a table: use `NumericCell` or `DeltaCell` in a [DataTable](?path=/docs/table-datatable--docs).
- A number over time: use a chart. A card shows one value, not a trend.
- A record with several fields: use [EntityCard](?path=/docs/data-entitycard--docs).

## Do and don't

Do:

- Set `unit` so the value is formatted for you (`kWh`, `kW`, `USD`, `percent`, `count`, `score`). Never pass a preformatted string.
- Set `goodDirection` per metric. Energy use and peak demand going down is good; savings going up is good. Use `none` when neither is.
- Set `deltaUnit` to match the delta: a fraction for `percent` (the default), the metric's own unit for an absolute change.
- Pass `state` from `fromQuery` so loading, refreshing and failure look like every other data component.
- Pass `value={null}` when there is no reading yet. The card shows the no-value dash and hides the delta.

Don't:

- Don't color the value or the delta yourself. Color comes from `goodDirection`, and status colors are reserved for meaning.
- Don't use `compact` for small numbers; it is for money and big totals in tight grids.
- Don't put a second number in `label` or `period`. One card, one number.

## Accessibility

- The value is a large paragraph, not a heading, so cards do not crowd the page outline. The label is an overline above it.
- A missing value reads as "No value" rather than a bare dash.
- The delta's direction is spoken as "up", "down" or "no change" next to the number, so it does not rely on the arrow or the color.
- While refreshing the card is marked busy; while loading it shows a skeleton announced as loading; on error it shows an alert with a Retry button.
- The caller provides a `label` that names the metric and its window, e.g. "Consumption, last 30 days". Icons are decorative.

## Composition

- Sits under a [PageHeader](?path=/docs/data-pageheader--docs), in a grid, above lists and tables.
- Uses `StatSkeleton` for loading and `ErrorState` for failure, the same states [DataState](?path=/docs/data-datastate--docs) renders.
- Leading icons come from `src/icons.tsx`, e.g. `BuildingIcon`.
