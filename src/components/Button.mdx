# Button

There is no Kilowatt `Button` component. Use MUI's `Button` and `IconButton` from `@mui/material` as MUI documents them. The theme is stock MUI apart from the departures in `src/mui/departures.ts`; for buttons the one that shows is sentence-case labels (no uppercase).

<Canvas of={ButtonStories.Primary} />

## Usage

```tsx
import Button from '@mui/material/Button';
import IconButton from '@mui/material/IconButton';
import { MoreIcon, PlusIcon } from 'src/icons';

<Button variant="contained" startIcon={<PlusIcon />} onClick={save}>
  New work order
</Button>

<IconButton aria-label="More actions" onClick={openMenu}>
  <MoreIcon />
</IconButton>
```

## Which variant

- `variant="contained"`: the primary action. One per view or dialog.
- `variant="outlined"`: a secondary action beside the primary one, or a standalone action.
- `variant="text"` (MUI's default): low emphasis, for toolbars, table rows and card headers.
- `IconButton`: an icon-only action in dense UI, such as a card's overflow menu.
- `color="error"`: only for the confirming button of a destructive action, inside an alert dialog (see Primitives/Overlays).

## Kilowatt rules

- Write labels in sentence case, as you want them shown ("Export CSV", not "EXPORT CSV"). The theme does not uppercase them.
- Icons come from `src/icons`, never `@mui/icons-material` (not installed). Pass a leading icon as `startIcon`.
- Use palette roles (`color="primary"`, `color="error"`) only; don't pass colors, and use `sx` only for layout.

## Loading

Set `loading` while the action runs. MUI disables the button and shows a spinner; with `loadingPosition="start"` the spinner replaces the `startIcon`. Change the label to say what is happening ("Dispatching…").

## Do and don't

Do:

- Name the action in the label ("Dispatch ticket", "Export CSV"), not "OK" or "Submit".
- Explain nearby why a disabled button is unavailable.

Don't:

- Don't put two contained buttons side by side.
- Don't run a destructive or irreversible action straight from a button; confirm it in an alert dialog.

## Accessibility

- MUI renders a native `button` with keyboard activation and a visible focus state.
- Give every `IconButton` an `aria-label`. Icons from `src/icons` are `aria-hidden`, so the label is the only accessible name.
- A `loading` button is disabled, so it leaves the tab order; keep the label meaningful and announce the result when the action finishes.
